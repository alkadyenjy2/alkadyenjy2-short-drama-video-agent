# Platform Fit — Evidence-First Policy

The agent does not assign fixed effort percentages, guaranteed growth rates, or fixed revenue rates to platforms.

Platform fit is determined from:
- observed performance metrics for the user's own published content;
- account eligibility and available API permissions;
- content format and platform requirements;
- rights/provenance status;
- current platform policy evidence.

Any monetary figure must come from an identified, dated, authoritative source and must not be presented as a guaranteed payout.

Production loop:

Discovery → Rights Review → Generation → Approval → Publish → Analytics → Learning

A platform cannot be marked successful without real publication or analytics evidence.
